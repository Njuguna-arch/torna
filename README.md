# ⚽ TORNA - Real-Money Football Tournament Web App

A lightweight, high-performance, mobile-first football tournament game built with HTML5 Canvas, Web Audio API, and an 8-player Knockout Financial Engine (M-Pesa Ksh 100 stakes, 30% platform commission, 70% winner cashout).

---

## 🚀 How to Test on Your Computer Right Now

You can open and play the game immediately:
1. Open the project folder: `c:\Users\pc owner\OneDrive\Attachments\OneDrive\Desktop\TORNA`
2. Double-click **`index.html`** to open it in your browser (Google Chrome, Edge, Brave, etc.).
3. Try:
   - **Practice Match**: Click `⚽ PRACTICE VS BOT (FREE)` to test dragging and shooting.
   - **Real Tournament Flow**: Enter your name, phone number, sample M-Pesa code (e.g. `MP984HKL2`), select your club, and click **SUBMIT & ENTER TOURNAMENT**.
   - Win 3 matches to see the champion payout screen!

## 🌐 How to Host on GitHub Pages (Free Web Link for WhatsApp)

Follow these 4 simple steps to get a link like `https://yourusername.github.io/torna`:

### Step 1: Create a GitHub Repository
1. Go to [github.com](https://github.com) and sign in.
2. Click the **`+`** icon in the top right and select **New repository**.
3. Name it **`torna`** (or `football-game`).
4. Keep it **Public** and click **Create repository**.

### Step 2: Upload Files
On the repository page:
1. Click **`uploading an existing file`**.
2. Drag and drop all the files from this folder (`index.html`, `style.css`, `game.js`, `tournament.js`, `audio.js`, `README.md`).
3. Click **Commit changes**.

### Step 3: Turn on GitHub Pages
1. In your GitHub repo, click **Settings** (top tab with gear icon).
2. On the left sidebar, click **Pages**.
3. Under **Branch**, select `main` (or `master`) and click **Save**.
4. Within 1 minute, GitHub will give you your live URL:
   `https://<your-username>.github.io/torna/`
